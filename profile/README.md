## Projects

| Project | What it is |
| --- | --- |
| [**Tabler**](https://github.com/tabler/tabler) | HTML dashboard UI kit built on Bootstrap 5, with more than 120 demo pages, dark mode and RTL |
| [**Tabler Icons**](https://github.com/tabler/tabler-icons) | Over 6,000 free MIT-licensed SVG icons, with packages for React, Vue, Svelte and Angular |
| [**Tabler Flags**](https://github.com/tabler/tabler-flags) | Over 250 optimized SVG country flags |
| [**Tabler Illustrations**](https://tabler.io/illustrations) | Customizable SVG illustrations in light and dark variants |
| [**Tabler Emails**](https://tabler.io/emails) | Responsive HTML email templates tested in more than 90 clients |
| [**Tabler Avatars**](https://tabler.io/avatars) | Avatar illustrations for user profiles and placeholders |
| [**tabler-starter**](https://github.com/tabler/tabler-starter) | Minimal starter template, ready to open in StackBlitz, CodeSandbox or Codespaces |
| [**Tabler Icons for Figma**](https://github.com/tabler/tabler-icons-figma) | Figma plugin for inserting Tabler Icons into your designs |

## Get started

Install the UI kit and the icons from npm:

```sh
npm install @tabler/core @tabler/icons
```

Or load Tabler straight from the CDN:

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@tabler/core@latest/dist/css/tabler.min.css" />
<script src="https://cdn.jsdelivr.net/npm/@tabler/core@latest/dist/js/tabler.min.js"></script>
```

The [documentation](https://docs.tabler.io) has setup guides for React, Vue, Angular, Next.js, Nuxt, SvelteKit, Astro, Laravel, Django, Rails and Symfony.

## Get involved

- Found a bug or have an idea? Open an issue in [tabler](https://github.com/tabler/tabler/issues/new/choose) or [tabler-icons](https://github.com/tabler/tabler-icons/issues/new/choose).
- Want to talk first? Join the [discussions](https://github.com/tabler/tabler/discussions).
- Want to send a pull request? Start with the [contributing guide](https://github.com/tabler/tabler/blob/dev/CONTRIBUTING.md).
- Follow [@tabler_io](https://x.com/tabler_io) for news and releases.
